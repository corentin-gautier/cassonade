| A refined interface | Always on | Restyled HUD, screens, title, world and server selection, loading map |

## Settings

- One on/off switch per feature, on by default, in a Mod Menu screen with one page per part of the mod. Same choices in `config/cassonade-settings.properties`.
- Server settings (rules, mobs, recipes, loot, structures) belong to the server and show greyed out on someone else's server. Client settings (interface, ambience, light, inventory helpers) are the player's.
- Some apply at the next world load or game start, or only in new chunks; the tooltip says so.

## Controls

All keys are rebindable (Options › Controls › Key Binds › Cassonade) and follow the printed character (AZERTY works). Table: README, "Controls".

| Status | Examples |

| Absent | The mod's items, blocks and recipes; server-side rules, structures, loot, mob behaviour |
