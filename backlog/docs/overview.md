## What it is

- Fabric mod, Minecraft 26.3, Java 25, Fabric API. Mod Menu optional (settings screen). Version in `gradle.properties`.
- Tagline: "Less friction, more life." Fixes many small survival annoyances and adds ambience, light, sea, villages and treasures.
- Players install it on the client; multiplayer needs it on the server too. A client stays usable on a server without it.
- Published on CurseForge, Modrinth and GitHub releases. Website: cassonademod.com. GPL-3.0.

## For whom

- Survival players who want the vanilla game, smoother and less empty.
- Not aimed at advanced technical players (redstone, mob farms): chunk loaders were turned down for that reason.
- Alternative to a modpack of many mods with mixed styles and many config screens.

## Rules for every feature

| Rule | Meaning |
| --- | --- |
| Same progression | No new ores, gear tiers, magic, machines, mobs, biomes or dimensions. Nothing that makes the game easier to beat; a better late reward yes, an early shortcut no. |
| Unlocked by a vanilla item | A tool shows up when a vanilla item (compass, clock) or one crafted from vanilla items (backpack, world map) is equipped in its slot. |
| Ambience is always on | Birds, sounds, sky give no advantage, so no item unlocks them. |
| Vanilla look | Minecraft's pixel style and sounds, in the mod's art direction: sepia wood, dark slots, leather, cream paper. |
| No customization | Each feature works one way. One on/off switch per feature, nothing else: no values, sliders or variants. Off = vanilla. |
| Server optional | Features that need the server fall back to vanilla on a server without the mod; those that need it are hidden. |
| Player input | Nothing done automatically without the player (why bed and portals are not recorded as places). |

Proposals are checked against these rules first; rejected ideas: [Turned down](/documentation/7/turned-down).
