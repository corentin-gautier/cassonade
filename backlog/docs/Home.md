Cassonade is a Fabric mod for Minecraft 26.3 that removes survival's small annoyances and brings the world to life, without changing how the game is played. Every feature as players see it: the root README (the reference for expected behaviour). Internals, textures, tests and releases in detail: CONTRIBUTING.md, searched by feature heading under "How the features work". Planned work: the tasks on this board.
